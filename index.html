Airline Booking Program

Python | Restoration

This project was originally developed for an assignment during my first year of A-level studies. With only a week remaining to finish and test the application, I wanted to create something that would stand out from the rest. During development, I independently researched and implemented a custom `goto()` navigation system. This allowed me to control different stages of the application, including passenger verification, baggage checks and security-related questions. I also developed various additional features throughout the project. Unfortunately, much of the original source code was lost, leaving only 172 lines that I have since managed to recover. Looking back, I believe this was the first programming project where I truly went above and beyond what was expected of me. It represents an important moment in my development as a programmer, when I began challenging myself to create something genuinely unique.
